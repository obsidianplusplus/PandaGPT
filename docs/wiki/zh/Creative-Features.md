# ✨ 创意功能

这些功能全部由 Agent 在对话中自动调用，玩家不需要记任何命令。

## 🏗️ 幽灵建筑预览

> `panda 在这里给我设计一个 7×7 的木屋，石砖地基，深色橡木屋顶`

Agent 用几何部件组合出一栋建筑，以**只有你能看到的假方块**显示在原地。世界不会被改动，几分钟后自动消失。预览完成后，Agent 会对照背包列出材料清单与缺口。

| 部件 `shape` | 用法 |
|---|---|
| `block` | 单个方块 |
| `fill` | 实心长方体 |
| `hollow` | 空心长方体（含地板与屋顶） |
| `walls` | 只有四面墙 |
| `line` | 两点之间的直线，适合屋脊、栏杆 |
| `cylinder` | 圆柱，可空心，适合塔楼 |
| `sphere` | 球体，可空心 |
| `pyramid` | 金字塔，可空心，适合屋顶 |

- 坐标以玩家朝向为准：x 向右、y 向上、z 向前；原点默认在玩家前方 2 格（`anchor=front`），也可以在脚下（`anchor=feet`）。
- 部件按顺序绘制，后面的覆盖前面的；用 `AIR` 挖出门窗。
- 满意后，Agent 可以把缺的材料设为目标，或把设计要点记成笔记。

| 配置 | 默认 | 说明 |
|---|---|---|
| `features.preview_max_blocks` | 2048 | 一次预览最多的方块数，超出会截断 |
| `features.preview_seconds` | 180 | 自动消失的秒数 |

## 🧭 粒子导航

> `panda 带我回家` · `panda 带我去刚才死的地方` · `panda 带我去 100 64 -200`

- 动作栏显示箭头、距离与高度差：`🧭 家 ↗ 128 格 · 高差 +12`
- 前方一段只有你能看到的粒子路线
- 到达后自动结束；离开目标所在的世界时结束
- 最长持续 `features.guidance_seconds`（默认 600 秒）

配置 `features.map_url` 后，Agent 还能给出可点击的网页地图链接（适用于 BlueMap、Dynmap、squaremap 等）：

```yaml
panda:
  features:
    map_url: 'https://map.example.com/#{world}:{x}:{y}:{z}:50:0:0:0:0:perspective'
```

## ⏰ 提醒

> `panda 十分钟后提醒我收麦子` · `panda 天黑前叫我回家` · `panda 日出时提醒我出门`

| 触发方式 | 说明 |
|---|---|
| `minutes` | 现实时间 N 分钟后 |
| `sunset` | 当前世界下一次日落 |
| `night` | 下一次入夜（怪物开始生成） |
| `sunrise` | 下一次日出 |

到点时播放提示音并显示 `[Panda 提醒] ⏰ 收麦子`。每人最多 `features.max_reminders` 条（默认 10，设为 0 关闭）。

## 💀 死亡回溯

> `panda 我刚死在哪？东西还在吗？`

记录最近一次死亡的位置、时间、原因与掉落物，并估算掉落物剩余时间（约 5 分钟后消失）。死亡后 Panda 会主动提醒一次，你可以直接说“带我回去”。死亡点会作为特殊地点进入记忆。

## 📊 统计与成就

> `panda 我今天挖了多少钻石？` · `panda 下一步做什么成就？`

- 生涯统计与本次上线以来的变化：游戏时长、死亡、击杀、挖掘、移动距离等
- 未完成成就按接近程度排序，并列出剩余条件

## 📝 个人笔记

> `panda 记一下我喜欢中式建筑` · `panda 待办：给村民建围墙` · `panda 我还有什么没做？`

笔记分为待办、关于你的事实（偏好、玩法风格）与普通备忘，长期保存，以后的建议会参考。完成待办时直接说“围墙建好了”，Agent 会删掉对应笔记。

## 🗡️ 物品检查

> `panda 我这把剑还能用多久？` · `panda 这件胸甲值得修吗？`

显示手持或穿戴物品的剩余耐久、附魔、铁砧修复费用、名称与描述。

## 🧑‍🌾 村民交易

> `panda 附近谁卖经验修补？` · `panda 哪个村民收小麦？`

列出你能看到的村民与流浪商人的交易，包括附魔书。

## 💡 更多创意玩法

以下玩法由多个工具与技能组合自然实现：

| 场景 | 组合 |
|---|---|
| 🗺️ “帮我规划今晚的探险” | exploration 技能 + 背包检查 + 入夜提醒 + 记录出发点 |
| ⚔️ “我准备好打末影龙了吗？” | combat 技能 + 物品检查 + 背包状态 |
| 🏠 “按我的风格设计一个仓库” | 读取笔记中的偏好 + 幽灵预览 + 材料目标 |
| 💰 “我攒够买地的钱了吗？” | Vault 余额 + 服务器资料中的价格 |
| 🧭 “最快怎么回主城？” | teleport 技能 + Essentials 传送点 + 距离比较 + 命令提案 |
