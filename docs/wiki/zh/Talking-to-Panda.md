# 💬 和 Panda 对话

> **玩家没有任何命令。** 在聊天开头说 `panda`（或 `@panda`），像跟朋友说话一样就行。

## 触发规则

- 只匹配聊天**开头**的触发词，后面可以跟空格、逗号或冒号：`panda 你好`、`@panda，帮我看看`、`Panda: 我在哪`。
- 聊天中间出现的 panda 不会触发。触发词可在 `panda.trigger_word` 中修改。
- 默认会隐藏触发 Panda 的那条聊天（`cancel_chat_message: true`），其他玩家看不到你的提问。
- 每位玩家同时只有一个进行中的回合，并有冷却时间（默认 5 秒）。
- 尊重其他插件已取消的聊天事件（例如禁言插件）。

回合进行时，动作栏会显示 Panda 正在做什么，例如 `👀 正在看…`、`🏗 正在搭建预览…`、`💰 正在查询余额…`。

## 对话示例

### 🧭 位置与导航

| 你说 | Panda 会做什么 |
|---|---|
| `panda 记住这里是我家` | 记下当前位置，名字为“家” |
| `panda 把这个箱子记下来` | 先看一眼确认你指的是哪个箱子，再记下它的精确坐标 |
| `panda 我家在哪？` | 告诉你距离、高度差与该往哪边转 |
| `panda 带我回家` | 开启粒子导航，动作栏显示箭头与距离，到达后自动结束 |
| `panda 我都记了哪些地方？` | 列出当前世界的地点 |
| `panda 忘掉矿洞入口` | 删除该地点 |

### 👁️ 看与理解

| 你说 | Panda 会做什么 |
|---|---|
| `panda 我面前这是什么？` | 重建你的第一人称画面，识别方块与对象 |
| `panda 左边那个熔炉怎么用？` | 用对象编号锁定熔炉，用私有粒子把它圈出来，再解释用法 |
| `panda 附近安全吗？` | 查附近生物、时间、光照，结合你的血量与装备给建议 |
| `panda 刚才这里有什么？` | 回忆最近的环境观察 |

### ⚒️ 合成与目标

| 你说 | Panda 会做什么 |
|---|---|
| `panda 我想做一把铁镐` | 设为目标并显示进度条，查本服真实配方，对照背包告诉你还差什么 |
| `panda 我现在能做什么？` | 列出现有材料马上能合成的物品 |
| `panda 我要去挖矿` | 检查火把、镐和食物，离家时提醒准备情况 |

### 🏗️ 创意与生活

| 你说 | Panda 会做什么 |
|---|---|
| `panda 在这里给我设计一个 7×7 的木屋` | 用只有你能看见的幽灵方块在原地预览，并列出还缺的材料 |
| `panda 十分钟后提醒我收麦子` | 设置现实时间提醒 |
| `panda 天黑前叫我回家` | 设置游戏事件提醒（日落 / 入夜 / 日出） |
| `panda 我刚死在哪？东西还在吗？` | 告诉你死亡点、原因、掉落物与剩余时间，并可带你回去 |
| `panda 记一下我喜欢中式建筑` | 写入长期笔记，以后的建议会参考 |
| `panda 我这把剑还能用多久？` | 耐久、附魔、修复费用 |
| `panda 附近谁卖经验修补？` | 列出能看到的村民与流浪商人的交易 |
| `panda 我今天挖了多少钻石？` | 本次上线与生涯统计 |
| `panda 下一步做什么成就？` | 按接近程度排序的未完成成就 |

### 🏙️ 服务器与插件

| 你说 | Panda 会做什么 |
|---|---|
| `panda 本服能圈地吗？` | 只按 `knowledge.md` 与已安装插件回答，不编造 |
| `panda 我有多少钱？买得起钻石剑吗？` | 读取 Vault 余额 |
| `panda 这块地是谁的？` | 查询 WorldGuard / GriefPrevention / Towny / Lands |
| `panda 我离下一个称号还差什么？` | 读取 LuckPerms 晋升路线 |
| `panda 谁拆了我的箱子？` | 查询 CoreProtect 方块记录（需要权限） |
| `panda 帮我回出生点` | 提出 `/spawn` 命令，显示确认按钮，等你点击或回答“执行吧” |

### 🤫 对话管理

| 你说 | 效果 |
|---|---|
| `panda 别打扰我` | 进入安静模式，不再主动提醒，隐藏目标进度条 |
| `panda 可以提醒我了` | 恢复主动辅助 |
| `panda 忘掉刚才的对话` | 清空对话历史；地点、目标与笔记保留 |

## 你什么都不说时

- 🛏️ 睡床或使用重生锚时，自动把重生点记为“家”。你亲口指定的家优先，不会被覆盖。
- 🔔 [主动式助手](Proactive-Assistant.md) 在值得注意的时刻（目标材料齐了、入夜仍远离家、死亡后物品即将消失）可能说一句简短的话，但大多数时候保持安静。
- ⚠️ 坠落、岩浆这类紧急局部风险直接显示在动作栏，不等待模型。
- 👀 后台低频观察周围的几何结构，供之后回忆；后台观察**不调用模型**、不产生费用。

## 回答的语言

Panda 用你提问的语言回答；无法判断时使用你的客户端语言。插件自身的提示文字按客户端语言显示，详见 [多语言](Languages.md)。
