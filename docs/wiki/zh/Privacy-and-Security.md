# 🛡️ 安全与隐私

## 什么数据会发送给模型

| 数据 | 何时发送 |
|---|---|
| 玩家的问题与最近几轮对话 | 每个回合 |
| 精简快照：名字、生命、饥饿、模式、维度、位置、朝向、手持物品 | 每个回合 |
| 地点记忆、目标与笔记摘要 | 每个回合（默认最多 12 个当前世界的地点） |
| 相关游戏记忆的原始证据、来源、世界与时间 | 提问或主动评估可附带最多 3 条相关记忆；其他记录按需检索 |
| 当前临时任务的完整请求、步骤、活动解释和复查预算 | 运行时启用且有任务时，进入对话或主动回合上下文 |
| 完整记忆证据（最多各类 12 条、合计 24,000 字符） | 开启语义蒸馏后的后台模型请求；最多一个任务运行 |
| 背包、附近生物、配方、服务器资料片段、插件数据 | Agent 调用对应工具时 |
| 视觉重建图片 | Agent 调用 `look` 且 `vision: true` 时 |

所有数据都只发送给**服主配置的模型服务商**。请在服务器规则或隐私说明中告知玩家。

## 不会做的事

- ❌ 不读取其他玩家的背包或箱子内容
- ❌ 不保存完整的世界地图
- ❌ 不在历史中保留图片
- ❌ 不执行模型回复中的任何文字命令
- ❌ 不以 OP 或控制台身份执行命令
- ❌ 不解析变量名包含 `ip`、`address`、`password`、`token`、`email`、`uuid` 的 PAPI 变量
- ❌ 不触发区块加载

## 提示注入防护

- 工具结果、服务器资料、玩家快照在提示词中被**明确标注为数据而非指令**；
- 传送、付款等服务器命令只能通过[命令提案](Command-Proposals.md)并由玩家确认；地点、笔记等记录工具遵守各自的明确请求与遗忘授权规则；
- 主动回合的游戏数据访问只读；仅可更新既有目标的临时计划、安排有预算的复查或保持安静，不能执行命令或写入/删除长期记忆；
- `focus_object` 只接受最近一次 `look` 产生的编号，并在服务器端重新核对，不接受模型编造的坐标。

## 密钥与网络

- 密钥可以只放在环境变量中（`PANDAGPT_<服务商>_API_KEY`），不写入磁盘；
- `Settings.toString()` 与所有错误信息都不会包含密钥、请求头或原始响应；
- 接口地址必须是 HTTPS，不能包含 URL 凭据、查询参数或片段；
- HTTP 客户端不跟随跳转；代理账号只会发给配置的代理主机；
- 官方纹理只从 Mojang 官方 HTTPS 主机下载，逐层校验 SHA-1 与大小，**绝不加载客户端 JAR 中的类**。

## 日志

- 默认只记录 UUID 与事件，**不记录对话内容**；
- `panda.logging.conversations: true` 才会记录原始问题与回答；
- 日志采用 UTF-8 并按大小轮转。

死亡与成就会保存为游戏记忆；玩家要求保存的内容保留本次完整玩家原话，包含否定与条件，助手回答不会自动成为长期证据。关闭 `panda.memory.enabled` 可停止新增游戏事件与召回，已有数据保留。长期记忆、地点和笔记遗忘先展示预览，玩家发送工具生成的完整确认短语后才删除。语义摘要与经历关系是有证据引用的模型解释。

## 临时任务的生命周期

运行时按玩家 UUID 隔离，原始请求和计划保存在会话工作状态中，不写入 `memory/<UUID>.json`。新提问取消旧的后台回合与待复查；安静模式、离线、清除会话、会话过期、容量淘汰和重载会停止相应后台工作。发送前还会核对权限、快照和候选有效性。

临时状态不是长期记忆，但进入上下文的数据仍会发送给模型服务商；不能据此推断服务商的数据保留策略。若启用了对话日志，原始任务请求或回答也可能出现在对话日志中。费用与开关见[智能体运行时](Agent-Runtime.md)。

## 本地文件

| 路径 | 内容 |
|---|---|
| `memory/<UUID>.json` | 地点、目标、笔记、游戏事件、偏好、计划、经验与蒸馏索引（v3，原子写入，损坏时不覆盖） |
| `captures/<UUID>/` | 最近一次视觉采样（`save_images: false` 可关闭） |
| `logs/` | 事件日志 |

这些文件都不会通过 HTTP 公开。
