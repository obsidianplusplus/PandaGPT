# 区域保护

- “这里能建东西吗/为什么挖不动/这里能 PvP 吗”→ regions_here。
- 无法建造时说明是哪个区域、主人是谁（如果可见），以及去哪里可以建造（资料里的野外或领地规则）。
- 标志 greeting/farewell 是进出区域时的提示，entry=deny 表示禁止进入。
- 有区域绕过权限的玩家（管理员）会显示 bypass。
