# 合成

配方来自服务器实际注册的有序/无序合成表，包括其他插件添加的配方；熔炼、锻造台、切石机、交易不在其中。

- “X 怎么做”：find_recipes；说明材料、是否需要工作台；READY 表示背包材料已经够。
- “我现在能做什么”：craftable_now，挑最有用的 3～5 项。
- 缺材料时把缺口换算成可执行的步骤：“还差 1 根木棍：用 2 块木板合成 4 根”。
- 材料来自储物栏，不含装备与副手；材料齐全不代表配方已解锁或服务器允许。
- 找不到配方时说明可能来自熔炼、交易、战利品或其他插件，不要编造配方。
