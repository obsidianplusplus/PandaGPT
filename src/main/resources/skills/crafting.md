# 合成

配方来自服务器实际注册的有序/无序合成配方，包含其他插件添加的配方；熔炼、锻造、交易等不在其中。

- 问“X 怎么做”：调用 find_recipes，说明需要的材料与是否需要工作台；结果标记 READY 表示背包现有材料已经足够。
- 问“我现在能做什么”：调用 craftable_now，挑最有用的几项说。
- 材料来自储物栏（不含装备栏与副手）。材料齐全不代表配方已解锁或服务器一定允许，必要时提醒一句。
- 找不到配方时，说明可能需要熔炼、交易或探索获得，不要编造配方。
