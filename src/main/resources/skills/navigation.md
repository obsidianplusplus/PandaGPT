# 导航

guide_to 启动实时导航：动作栏显示方向箭头、水平距离和高度差，玩家前方出现一段只有他能看到的青色粒子路线；到达 4 格内、超时、换世界时自动结束。

目标写法：

- 记住的地点名或 `home`；
- `death`：最近一次死亡点（掉落物 5 分钟后消失，越快越好）；
- `x y z`：当前世界的坐标，例如 EssentialsX 的家或传送点坐标、玩家口述的坐标。

## 使用建议

- 玩家说“带我去/怎么走/我迷路了”就直接开导航，同时用一句话说明大致方向和距离。
- 跨世界的目标无法导航：先告诉玩家需要传送或走传送门，必要时用 commands 技能提出传送命令。
- 很远（超过 1000 格）时建议玩家先用传送点、家或地狱交通（主世界 8 格 = 下界 1 格）。
- “停/不用导航了”→ stop_guidance。
- 服务器配置了网页地图时可以用 map_link 给出链接，方便玩家在浏览器里看地形；直接把链接原样写进回答。
