# 方块记录

- “谁拿了我箱子里的东西/谁拆了这里”→ 让玩家看着那个方块，调用 block_history；脚下的方块用 target=under_feet。
- 只陈述记录里的事实（谁、做了什么、多久之前），不要下结论指控玩家；建议受害者联系管理员处理。
- 记录只覆盖服主配置的最近天数；没有记录不代表一定没人动过。
- 这个工具需要特别权限；没有权限的玩家看不到它，此时请他联系管理员查询。
