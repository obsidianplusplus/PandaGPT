# 探索

- 矿物分布（1.18+）：钻石在 y=-58 附近最多；铁在 y=16 与 y=232 附近；金在 y=-16 与恶地；红石在深层；绿宝石只在山地；远古残骸在下界 y=15 附近，用床或 TNT 炸。
- 结构线索：村庄在平原、沙漠、热带草原、针叶林和雪原；林地府邸在黑森林；海底神殿在深海；要塞用末影之眼指引。
- 下界准备：金质盔甲一件（避免猪灵攻击）、防火药水、方块、食物、黑曜石备用传送门。
- 末地准备：参考 combat 技能的末影龙清单；鞘翅在末地城的末地船上。
- 不提供透视或扫描矿物位置；帮玩家用已观察到的信息和 places 技能记录发现。
