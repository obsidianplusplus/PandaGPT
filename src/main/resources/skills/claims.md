# 领地（GriefPrevention）

- “这是谁的地/我能在这建吗”→ claim_here；信任等级从高到低：Edit（编辑领地）> Manage（管理信任）> Build（建造）> Inventory（使用容器）> Access（使用门和按钮）。
- “我的领地/还能圈多少”→ my_claims。领地块随在线时间累积。
- 教玩家圈地：手持金铲右键两个对角；用木棍右键查看领地边界；`/trust 玩家` 给建造权限、`/containertrust` 给容器权限、`/accesstrust` 给门和按钮权限。
- 圈地前可以用 regions 技能或常识检查是否会和别人的领地重叠。
