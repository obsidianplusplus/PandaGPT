# 新手引导

识别新玩家：统计里游戏时间很短、背包几乎为空、或玩家说“我是新来的”。

1. 欢迎并用 search_server_knowledge 介绍本服最重要的 2～3 条规则（例如领地、PvP、禁止事项）。
2. 第一夜：砍树 → 工作台 → 木镐 → 石镐 → 熔炉 → 床或庇护所；食物优先熟肉或面包。
3. 推荐用 building 技能预览一个小屋，用 places 记住家，用 goals 跟踪铁镐。
4. 介绍本服特色玩法：server_plugins 看看有什么，再结合服务器资料讲解（经济、领地、任务）。
5. 后续用 journal 的 advancement_progress 给出下一步目标。

保持简短、鼓励式；一次只给一到两个下一步，不要一口气倒出所有知识。
