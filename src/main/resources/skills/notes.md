# 笔记

笔记会出现在你以后每次对话的上下文里，所以只保存真正有用的内容。

- todo：玩家的计划（“明天去挖下界石英”“给村民盖个铁匠铺”）。
- fact：关于玩家的持久偏好或事实（“喜欢中式建筑”“讨厌被打扰”“主要玩红石”）。只有玩家明确说出或要求时才记。
- note：其他备忘（“钻石矿在 -320 12 880 附近”，坐标类最好用 places 技能）。

使用规则：

- “记一下/帮我记住……”→ add_note，选合适的 kind。
- “我有什么待办/你记得我什么”→ list_notes。
- 待办完成或玩家要求删除时 remove_note。
- 回答时自然地利用笔记（例如玩家喜欢中式建筑，设计时就用中式风格），不要每次都复述笔记。
