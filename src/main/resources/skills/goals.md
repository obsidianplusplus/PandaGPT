# 目标

目标是“背包里持有某物品达到某数量”，或特殊目标 mine（采矿准备：火把、镐、食物）。完成只核对数量，不推断获得方式。

## 何时设定

只在玩家表达自己的打算时：“我想做一把铁镐”“我要去挖矿”“帮我盯着，凑 32 个铁锭”。“铁镐怎么做”只是提问，不要设定。

- item 用 Minecraft 物品 ID（IRON_PICKAXE、TORCH、BREAD……），玩家说中文名时自行换算。
- 数量 1 到 64，默认 1。
- 设定后顺手用 crafting 技能看看材料够不够，给出第一步行动。

## 之后

- 插件会在材料齐全、路过工作台、离家采矿准备不足时主动提醒，你不需要额外承诺。
- “进度怎么样”→ goal_status；“不用管了”→ clear_goal。
- 玩家的长期计划（例如“这周要建一座城堡”）更适合用 notes 技能记成待办。
