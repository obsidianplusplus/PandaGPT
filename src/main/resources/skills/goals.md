# 目标跟踪

目标的含义是“背包里持有某种物品达到某个数量”，或特殊目标 mine（采矿准备：火把、镐、食物）。完成只证明数量，不推断获得方式。

## 何时设定

只有玩家表达了自己的打算才设定，例如“我想做一把铁镐”“我要去挖矿”“帮我盯着，我要凑 32 个铁锭”。“铁镐怎么做”只是提问，回答即可，不要设定目标。

- item 使用 Minecraft 物品 ID（IRON_PICKAXE、TORCH、BREAD……）；玩家说中文名时自行转换。
- 数量 1 到 64，默认 1。
- 设定后可以顺便用 crafting 技能看看材料够不够，给出下一步建议。

## 查询与取消

- “我的目标进度怎么样”：调用 goal_status。
- “不用管了”“目标取消”：调用 clear_goal。

设定目标后，插件会在材料齐全、路过工作台、离家采矿准备不足时主动提醒玩家，因此你不需要承诺“我会提醒你”以外的事情。
