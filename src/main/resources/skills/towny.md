# 城镇（Towny）

- “我在哪个城镇/城镇有多少钱”→ towny_status。
- “这块地是谁的/能买吗”→ towny_plot_here；FOR SALE 时可以提案 `plot claim`（玩家确认后执行）。
- 新玩家没有城镇时，介绍加入方式（`town join <名字>` 需要城镇开放）或建城（`town new <名字>`，需要费用，先查服务器资料）。
- 城镇每日维护费不足会导致城镇解散，城镇银行偏低时可以提醒。
